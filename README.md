# 📝 Markly - a web app for managing bookmarks

## Users should be able to:

[ ] Add new bookmarks with a title, description, website URL, and tags </br>
[ ] View all their bookmarks </br>
[ ] See bookmark details, including favicon, title, URL, description, tags, view count, last visited date, and date added </br>
[ ] Search for bookmarks by title in the search bar </br>
[ ] Filter bookmarks by selecting one or multiple tags from the sidebar </br>
[ ] Reset tag filters to view all bookmarks again </br>
[ ] View archived bookmarks </br>
[ ] Archive bookmarks to remove them from the main view without deleting them </br>
[ ] Pin/unpin bookmarks to keep important ones easily accessible </br>
[ ] Edit existing bookmarks to update their details </br>
[ ] Copy bookmark URLs to the clipboard </br>
[ ] Visit bookmarked websites directly from the app </br>
[ ] Sort bookmarks by "Recently added", "Recently visited", or "Most visited" </br>
[ ] Toggle between light and dark color themes </br>
[ ] View the optimal layout for the interface depending on their device's screen size </br>
[ ] See hover and focus states for all interactive elements on the page </br>
