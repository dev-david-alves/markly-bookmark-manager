# 📝 Markly - a web app for managing bookmarks

## Users should be able to:

[x] Add new bookmarks with a title, description, website URL, and tags </br>
[x] View all their bookmarks </br>
[x] See bookmark details, including favicon, title, URL, description, tags, view count, last visited date, and date added </br>
[x] Search for bookmarks by title in the search bar </br>
[x] Filter bookmarks by selecting one or multiple tags from the sidebar </br>
[x] Reset tag filters to view all bookmarks again </br>
[x] View archived bookmarks </br>
[x] Archive bookmarks to remove them from the main view without deleting them </br>
[x] Pin/unpin bookmarks to keep important ones easily accessible </br>
[x] Edit existing bookmarks to update their details </br>
[x] Copy bookmark URLs to the clipboard </br>
[x] Visit bookmarked websites directly from the app </br>
[x] Sort bookmarks by "Recently added", "Recently visited", or "Most visited" </br>
[ ] Toggle between light and dark color themes </br>
[ ] View the optimal layout for the interface depending on their device's screen size </br>
[x] See hover and focus states for all interactive elements on the page </br>
